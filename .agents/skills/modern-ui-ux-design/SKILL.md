# Modern UI/UX Design Skill

## 1. Visual Hierarchy & Rhythm
- High-contrast headings vs subdued meta text.
- Balanced whitespace padding and breathing room.
- Dynamic layouts: Split screens, Bento grids, layered cards, floating badges.

## 2. Modern Styling Techniques
- **Glassmorphism**: `backdrop-filter: blur(12px)`, translucent borders (`rgba(255,255,255,0.1)`), subtle shadows.
- **Lighting & Shadows**: Layered soft ambient drop-shadows instead of harsh dark outlines.
- **Borders & Accents**: Subtle hairline borders (`1px solid hsl(var(--border) / 0.15)`), gradient border glows.

## 3. Component Architecture
- Buttons with distinct primary, secondary, ghost, and destructive states.
- Clean modals, slide-overs, drawer menus, dropdowns, and toast notifications.
- Accessible form fields with floating labels, clear focus rings, and inline validation states.
